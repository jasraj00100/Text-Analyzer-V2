# Text Analyzer V2

A C++ console application that analyzes text and provides useful statistics about its contents.

## Features

- Letter frequency analysis (a-z)
- Digit frequency analysis (0-9)
- Space counting
- Word counting
- Total character counting
- Special character counting
- Multi-line text input support
- Case-insensitive text processing

## Technologies Used

- C++
- Arrays
- String Manipulation
- Functions
- Character Hashing

## How It Works

1. Enter text (supports multiple lines).
2. Press Enter twice to finish input.
3. The program analyzes the text and displays:
   - Letter frequencies
   - Digit frequencies
   - Number of spaces
   - Number of words
   - Total characters
   - Special characters

## Example

### Input

```
Hello World! 123
```

### Output

```
d -> 1
e -> 1
h -> 1
l -> 3
o -> 2
r -> 1
w -> 1

1 -> 1
2 -> 1
3 -> 1

spaces -> 2

Words -> 2

Total Characters -> 16

Special Characters -> 1
```
